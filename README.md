# 📚 Telegram Bot: Нагадувач розкладу занять (aiogram 3)

Telegram-бот для студентів на базі **aiogram 3** та **SQLite**, який надає зручний доступ до розкладу занять, підтримує індивідуальний вибір загальної академічної групи (ОПП) та окремої групи з англійської мови, автоматично відстежує навчальні тижні (відлік з 01.09.2026 з чисельником/знаменником) та надсилає автоматичні нагадування перед кожною парою.

---

## 🌟 Основні можливості

- 👥 **Роздільні групи**: Можливість окремо обрати загальну групу (наприклад, `ІПЗ-21`) та підгрупу з англійської мови (`Eng-B2.1`, `Eng-B2.2` тощо). Розклад автоматично об'єднується.
- 📆 **Розрахунок тижнів**: Автоматичне визначення номера тижня та типу (1-й тиждень / Непарний, 2-й тиждень / Парний). Початок семестру — `01.09.2026`.
- 🔔 **Автоматичні нагадування**: Фоновий планувальник занять (APScheduler), що завчасно (наприклад, за 10 хв) надсилає сповіщення з назвою дисципліни, типом пари, викладачем, аудиторією або посиланням на онлайн-зустріч.
- ⚡ **Зручні команди та меню**:
  - `📅 Сьогодні` (`/today`) — розклад на поточний день з урахуванням тижня.
  - `🗓️ Завтра` (`/tomorrow`) — розклад на завтрашній день.
  - `📆 На тиждень` (`/week`) — огляд розкладу на робочий тиждень з можливістю перемикання між 1-м та 2-м тижнями за допомогою кнопок.
  - `⏳ Зараз` (`/now`) — статус поточної пари та наступне заняття.
  - `⚙️ Налаштування` (`/settings`) — зміна груп, часу нагадування (5, 10, 15, 20, 30 хв) або вимкнення сповіщень.
  - `ℹ️ Допомога` (`/help`) — довідка щодо функціоналу бота.

## 🚀 Встановлення та запуск

### 1. Клонування репозиторію та створення віртуального середовища

Використовуючи **uv**:
```bash
uv venv
.venv\Scripts\activate      # Windows
# source .venv/bin/activate # Linux / macOS
uv pip install -e .
```

Або стандартний **pip**:
```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
# source .venv/bin/activate # Linux / macOS
pip install -r pyproject.toml
```

### 2. Налаштування токена бота (`.env`)

Скопіюйте файл `.env.example` у `.env`:
```bash
cp .env.example .env
```

Відкрийте `.env` та вкажіть ваш токен, отриманий у [@BotFather](https://t.me/BotFather):
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TIMEZONE_NAME=Europe/Kyiv
SEMESTER_START_DATE=2026-09-01
DATABASE_PATH=bot_database.sqlite3
DEFAULT_NOTIFY_MINUTES=10
```

### 3. Запуск бота

```bash
python main.py
```

## ✍️ Як налаштувати / змінити розклад занять

Розклад зберігається у зручному форматі JSON у файлі [`bot/data/schedule.json`](bot/data/schedule.json).

Приклад структури заняття:
```json
{
  "opp_groups": ["ІПЗ-21", "КН-21"],
  "english_groups": ["Eng-B1.1", "Eng-B2.1", "Eng-B2.2", "Eng-C1"],
  "lessons": [
    {
      "id": "ipz21_mon_1",
      "group": "ІПЗ-21",
      "subject": "Архітектура програмного забезпечення",
      "type": "Лекція",
      "teacher": "проф. Мельник В.О.",
      "room": "ауд. 402 (Головний корпус)",
      "day_of_week": 0,
      "week_type": "all",
      "start_time": "08:30",
      "end_time": "10:05"
    },
    {
      "id": "eng_b21_mon_3",
      "group": "Eng-B2.1",
      "subject": "Іноземна мова за проф. спрямуванням (English B2)",
      "type": "Практика",
      "teacher": "ст. викл. Сміт О.В.",
      "room": "ауд. 512 / https://zoom.us/j/123456789",
      "day_of_week": 0,
      "week_type": "all",
      "start_time": "12:20",
      "end_time": "13:55"
    }
  ]
}
```

### Поля заняття:
- `group`: Назва групи ОПП або підгрупи з англійської.
- `day_of_week`: `0` — Понеділок, `1` — Вівторок, ..., `5` — Субота.
- `week_type`: `"all"` (кожного тижня), `"1"` (лише 1-й тиждень / чисельник), `"2"` (лише 2-й тиждень / знаменник).
- `room`: Номер аудиторії або пряме посилання на відеоконференцію (Google Meet, Zoom, MS Teams).
